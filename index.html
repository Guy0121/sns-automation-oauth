SNS Automation OAuth

SNS Automation OAuth is a personal automation application used by the app owner to connect their own Google account with GitHub Actions.

What this app does

The application uses Google APIs to support automated video upload and management for the owner's Tech&Art YouTube channel. It is intended for the owner's own account and is not offered as a public consumer service.

How it works

The owner authorizes access through Google OAuth. GitHub Actions then uses the authorized credentials only for the requested automation, such as uploading videos and managing related YouTube content.

Privacy

Please see the Privacy Policy for details about how Google account data and OAuth credentials are handled.
