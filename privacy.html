Privacy Policy

Last updated: September 19, 2026

This Privacy Policy describes how SNS Automation OAuth handles information when the app owner connects their Google account for personal automation.

1. Purpose of the application

SNS Automation OAuth is a personal-use application that connects the owner's Google account with GitHub Actions in order to automate video upload and management for the owner's Tech&Art YouTube channel.

2. Google account data accessed

The application may access only the Google account permissions explicitly granted by the owner through Google's OAuth consent screen. These permissions are used only to perform the requested YouTube automation functions.

3. Use of information

Google user data is used solely to authenticate requests and perform authorized operations such as uploading videos or managing YouTube content. The application does not use Google user data for advertising, profiling, or unrelated purposes.

4. Storage and security

OAuth credentials used by the automation may be stored as protected GitHub repository or GitHub Actions secrets. Credentials are not intentionally exposed in public source code. Access is limited to the automation environment controlled by the app owner.

5. Sharing of information

Google user data is not sold, rented, or shared with third parties for advertising or marketing purposes. Data is transmitted only to services required to perform the authorized workflow, such as Google APIs and GitHub Actions.

6. Data retention

Authentication credentials are retained only as long as needed for the automation. The owner may revoke the application's access at any time from their Google Account security settings and may remove stored credentials from GitHub.

7. User control

The app owner can review or revoke Google account access from Google's account security settings. Revoking access prevents future API requests that require the revoked authorization.

8. Changes to this policy

This policy may be updated if the application's functionality or data handling changes. The latest version will be published on this page.
